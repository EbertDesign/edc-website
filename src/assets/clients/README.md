Client logos for the "Trusted by" marquee on the home page.

Drop one file per client here (SVG preferred; PNG or WebP also work). They are
picked up automatically, in filename order, and the filename becomes the alt
text: `b-lab.svg` reads as "B Lab". Prefix with a number to set the order —
`01-b-lab.svg` — and the number is dropped from the alt text.
